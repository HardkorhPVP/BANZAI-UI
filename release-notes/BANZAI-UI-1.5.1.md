# BANZAI UI 1.5.1

## WoW Forever

- Added WoW Forever 1.60.1 support.
- Added Forever-aware BANZAI profile and client adaptation.
- Added Restore Pre-Banzai support on Forever.
- Added optional BANZAI Window Skins.
- Added Zygor visual integration.
- Added optional Baganator visual integration.
- Fixed Forever Chat integration.

## BANZAI Weave

- Added BANZAI Weave, the new BANZAI-owned irregular diagonal slash StatusBar texture.
- BANZAI Weave is now the default bar texture.
- Depleted health and resource regions retain a darker version of the same textured material.
- Active regions preserve their normal semantic colours.
- BANZAI Smooth remains available as an alternative.
- BANZAI Weave has been live-validated on Retail / Midnight and WoW Forever.

## Compatibility

- Retail / Midnight 12.1.5
- WoW Forever 1.60.1
- One BANZAI UI package supports both clients.

## Known / Deferred Live Validation

- Dedicated Forever healer-role live validation remains deferred.
- Dedicated Forever PvP / Arena / Battleground live validation remains deferred.
- Forever own-cooldown bar mappings remain a known limitation.
