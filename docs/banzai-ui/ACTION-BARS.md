# Action bars

BANZAI gives the action buttons their own look. The bars themselves - which spells sit where, paging, keybinds - are ElvUI's and yours and are never changed.

Page: **BANZAI > ACTION BARS**.

## BUTTON STYLE

**Button style** (a reload applies it):

| Choice | Look |
|---|---|
| **Banzai Square** (default) | square buttons with a green -> purple border, compact keybind at the top-right |
| **Banzai Circles** | round buttons with a green -> purple ring and a centred keybind |
| **ElvUI Square** | ElvUI's plain square buttons |

## BANZAI BUTTONS

Available for the Banzai styles (not ElvUI Square):

- **Button size** - 26-32 (30 = BANZAI); up to 32 so the two rows stay clear of the cooldown bars. A reload applies it.
- **Spacing** - 4-7 between buttons (6 = BANZAI). A reload applies it.
- **Border / ring intensity** - 40-100 %: strength of the border or ring, drawn live.

## KEYBIND / COUNT

- **Keybind size (circles)** - 100-160 % of Bushido's keybind size (130 % = BANZAI) for the circles' centred keybind; the square keeps its compact keybind. A reload applies it.
- **Charge / stack count size** - 60-120 % (80 % = BANZAI). A reload applies it.

## Notes

- Button style, size, spacing and text sizes are visual settings and are carried by Character Sync; the spells on the bars never are.
- **UNIT FRAMES > PLAYER / TARGET / FOCUS / TOT > Target cooldown bars** controls Bushido's extra bars 2 and 4 between Player and Target (off in BANZAI; the spells stay on the bars).
