## BANZAI UI

Design, code, bamboo art, wordmark and class identity artwork: **Darren (HARDKORH)**.

BANZAI UI grew out of a private restoration of the JiberishUI Shinto/Bushido look and is published with the permission Darren established with its original author. The original author does not endorse, support or maintain BANZAI UI; please do not contact JiberishUI about it.

## Class identity artwork

The thirteen class identity images shown in the BANZAI SPLIT central circles and party circles (and, with *BANZAI everywhere*, the classic Focus / Party / Boss circles) are **Darren's original art, generated for BANZAI with Gemini**. They are not Blizzard art and no Blizzard icon was used as a source.

## Separate projects BANZAI UI runs on or with

These are their authors' own work under their own licences. None of them is included in the BANZAI UI zip; install them from their authors.

| Project | Role |
|---|---|
| **ElvUI** | required - the UI framework BANZAI UI's profile layer configures |
| **JiberishMedia** | required - media the Bushido layout uses; separate download, its own licence |
| Details! Damage Meter | optional - the DAMAGE / HEALING meters |
| ElvUI_mMediaTag and !mMT_MediaPack | optional - portraits, role icons, cast ring |
| ElvUI_EltreumUI (Eltruism) | optional - nameplate and frame details |
| JiberishIcons | optional - the Fabled class / spec art |
| !KalielsTracker | optional - hidden while the Banzai tracker is on |
| MinimapButtonButton | optional - the minimap-button collector |
| Syndicator | optional - gold of your other characters and the Warband bank, read only |
