# Support

BANZAI UI is **not supported by JiberishUI**. Please do not contact JiberishUI about BANZAI UI; report here instead.

## Before you ask

1. Read [TROUBLESHOOTING.md](TROUBLESHOOTING.md) and [FAQ.md](FAQ.md).
2. `/reload`.
3. Check that ElvUI and JiberishMedia are installed and enabled, and that both **Banzai** and **Banzai Art** are ticked.

## Where

- **Issue tracker** - `https://github.com/HardkorhPVP/BANZAI-UI/issues` - for reproducible bugs with the details below.
- **Discord** - `https://discord.gg/sv2WNwk2WZ` - questions and quick help.

## What to include

| | |
|---|---|
| `/banzai status` | copy the whole chat output: version, ElvUI profile, frame theme, panel style, buffs panel, frame style, sync state, recorded previous state |
| Lua error | the full text from **BugSack** / **BugTabs** or the game's error window, if there was one |
| Screenshot | with the affected frame visible; for a font or parchment readability report, a full-size (not scaled) crop |
| What happened | one or two sentences; what you expected instead |
| How to see it again | steps, if you know them |
| Setup | BANZAI CLASSIC or SPLIT, the display font, which optional addons are installed (COMPONENTS page) |
| Other addons | anything else that touches unit frames, nameplates, the objective tracker or Details |

## Not in scope

Problems inside ElvUI, JiberishMedia, Details!, mMediaTag, Eltruism, Kaliel's Tracker or any other separate addon belong to their authors - unless BANZAI UI's settings are what causes them, in which case report here with `/banzai status`.
